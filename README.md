# Web Development Practice

Three web pages I built while learning HTML and CSS, from my first ever web page in 2022 to a styled multi-section site in 2023.

## The pages

### Basic website (September 2022)
**[View it live](https://rsmithcoding.github.io/WebDev/BasicWebSite/)** · `BasicWebSite/index.html`

My first web page: a heading, text and a logo image, styled with a few CSS rules for size, rounded corners and layout.

### Basic form (September 2023)
**[View it live](https://rsmithcoding.github.io/WebDev/Basic%20Form/BasicForm.html)** · `Basic Form/BasicForm.html`

A sign-up form with name and email fields and styled Subscribe and Close buttons.

### Car competition site (September 2023)
**[View it live](https://rsmithcoding.github.io/WebDev/Competition-page/Car-Competition.html)** · `Competition-page/`

A mock-up of a car raffle website, using everything I'd learned up to that point. It has a navigation menu, login and sign-up buttons, and prize cards with an image, description and "buy ticket" button for each car. The styling is in a separate CSS file, with a grid layout and hover effects.

## Built with

- HTML
- CSS

## What I learned

- Structuring a page with HTML elements such as headings, paragraphs, images and buttons
- Building a simple form with input fields
- Styling with CSS: classes, colours, borders, rounded corners and sizing
- Moving styles into a separate stylesheet
- Laying out a page with nested `div`s and CSS Grid
- Adding interaction with `:hover` and `:active` states
